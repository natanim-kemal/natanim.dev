# natanim.dev

Personal site of Natanim Kemal: portfolio, experience, projects, and a Markdown-powered blog.

## Develop

```bash
bun install
bun dev
```

## Blog posts

Add a `.mdx` file to `content/blog/` with `title`, `date`, and `description` frontmatter.

## Contact form

Set `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID` in `.env.local`; submissions are forwarded to Telegram.
